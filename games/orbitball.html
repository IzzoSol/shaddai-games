ORBITBALL — Pilot VEXA rides the rim of Station Nine, a pinball table hung in orbit above a green world. Launch the ball up the plunger lane, keep it alive with the flippers, and light up the table: pop bumpers +100, slingshots +50, the spinner +100 a spin, rollover lanes spell O-R-B-I-T for +250 a letter — finish the word and the table opens MULTIBALL. Drop all four targets for +5,000, ride the orbit lane for +1,000. Three balls a game; a ball save guards you for six seconds after every launch. Nudge the table, but nudge too hard and it TILTS.
Controls: Z / ← left flipper · / or → right flipper · hold SPACE to charge the plunger, release to launch · X nudge · V ball-cam · P pause · M mute.
WATCH is a council bot pilot on the Fallible Engine — a different agent rides the flippers each ball, judging the ball's fall by personality, and learning from every drain. They misjudge on purpose — never frame-perfect. If the engine fails to load, the old ROOK / SPARK / DRIFT stand-ins play instead.
📱 Handheld shell: on phones the game sits in its own console: ◀ left flipper, A right flipper, hold B to charge the plunger, ▲ nudge, START opens the menu (resume / save state / load state / restart / quit), SELECT toggles ball-cam.
Clean-room: pinball formula, our own code, table, pilot and art — no copied assets, names or code. Space Cadet Pinball's MIT decompilation is a design reference only; nothing from it was run, copied or moved into this file.
