MINIMARCH — the mini-bots march mindlessly forward, and only you can save them. Click a marcher (or move the cursor and press A) to give it a job: BLOCKER stands and turns the rest around, BUILDER lays a staircase, DIGGER digs straight down, BASHER digs forward, MINER digs diagonally down, CLIMBER scales walls, FLOATER opens a canopy and survives long falls, BOMBER clears dirt with a blast. Save the quota before the timer runs out — a long fall splats, water and lava drown, steel cannot be dug. Keys 1–8 pick a job, V marcher-cam, P pause, R restart.
WATCH is a council bot rescuer on the Fallible Engine — it scores every (marcher, job) pairing and picks by personality, so it digs the wrong hole sometimes. If the engine fails to load, the NOVA / TURTLE / ZEROX stand-ins rescue instead. Every decision is a recorded trace.
📱 Handheld shell: on phones the game sits in its own console: D-pad moves the cursor, A applies the selected job to the nearest marcher, SELECT cycles the job, B toggles marcher-cam, START opens the menu (resume / save state / load state / restart / quit).
⛶ Fullscreen (F): the shell fills the screen — Esc exits first, P still pauses.
Clean-room: the marcher-rescue formula, our own code, levels, characters and art — no copied assets, names or code. Design reference: Lix (CC0) for level concepts only.
