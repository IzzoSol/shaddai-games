DEEPDIG — MOLO the mole-bot tunnels the garden grid under Cindral Reach. Dig through the dirt (+10 a tile), pump your hose into a pest and inflate it till it POPS (deeper pops pay more: 200 / 400 / 600 / 1,000), and undermine the boulders — a falling rock crushes everything under it (1,000 / 2,000 / 4,000 / 6,000). Drop two rocks and a GLOWMELON ripens in the start tunnel — grab it before it fades. The SPROUTS chase you through the tunnels and ghost through the dirt when they lose you; the EMBERWYRMS breathe fire down a clear tunnel. Clear every pest to take the next level.
Controls: arrows / WASD dig + steer · hold SPACE to pump (4 pumps pops) · V miner-cam · P pause · M mute · R restart.
WATCH is a council bot miner on the Fallible Engine — a different agent works the grid each game, judging when to dig, pump and drop rocks, and learning from every squish. They misjudge on purpose — never frame-perfect. If the engine fails to load, the old ROOK / SPARK / DRIFT stand-ins dig instead.
📱 Handheld shell: on phones the game sits in its own console: D-pad steers MOLO, A pumps, B toggles miner-cam, START opens the menu (resume / save state / load state / restart / quit), SELECT toggles miner-cam.
Clean-room: the dig-and-pump formula re-implemented from documented behaviour in our own code (SPEC lane — the Atari 7800 original source for the 1982 arcade digger is read-as-spec only; see scan3.md §9). All names, levels, characters and art are original — no copied code, assets or names.
