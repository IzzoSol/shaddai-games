The deep waits.

NOVA the spelunker-bot descends the Gloamdeep. Grab the gold, mind the spikes, reach the door.
Controls: ← → / A D run, SPACE / W / ↑ jump (hold for higher), ↑ ↓ climb ladders & ropes, X / J whip, C bomb, E throw rope, V delver-cam, P pause, M mute, R restart floor.
📱 Handheld shell: on phones the game sits in its own console: D-pad to run & climb, A jumps, B whips, START opens the menu (resume / save state / load state / restart / quit), SELECT toggles delver-cam.
Rules: every floor is grown from one seed — the same seed always grows the same caves. Gold +100, gems +500, the Heartstone Idol +1000 (it wakes the boulder). Spikes, arrows, mites, bats and spiders all cost a heart; a long fall costs one too. Linger past 2:30 and the Wisp comes for you. Reach the door on floor 3 to win.
Clean-room note: procedural cave-delving mechanics follow the documented behaviour of the classic 2008 spelunking platformer (SPEC lane — the complete original source is public and readable; read as text only, rewritten here in our own code — no code, art, names or levels copied). The caves, NOVA and every line of art are original.
