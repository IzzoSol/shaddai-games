STACK CLASH — a versus falling-block stacker, built clean-room from the documented mechanics of the genre: seven block shapes, a 10-wide well, line clears that send garbage rows to the other side. Clear 1 line: nothing sent. 2 lines: 1 garbage row. 3 lines: 2 rows. 4 lines (QUAD): 4 rows. First pilot to 3 rounds takes the match — a round ends when a well tops out. ← → move · ↓ soft drop · ↑ / X rotate · SPACE hard drop · C hold · V drop-cam · P pause · M mute. 2P duel: P2 plays A / D move, S soft, W rotate, G hard drop, F hold.
WATCH is two council bots stacking against each other through the Fallible Engine — each picks its placement from scored options by personality, so they misplace, gamble on quads, and tilt after a bad round. Never frame-perfect. If the engine fails to load, the ORBIT / HALO / RUSH stand-ins stack instead.
📱 Handheld shell: on phones the game sits in its own console: D-pad moves the piece, A rotates, B holds, ⤓ hard-drops, START opens the menu (resume / save state / load state / restart / quit), SELECT toggles drop-cam.
Clean-room: the falling-block versus formula, our own code, pilots and art — no copied assets, names or code. The Tetris name, brand and original art are not ours and are not used.
